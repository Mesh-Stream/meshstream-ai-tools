# MeshStream 隐私协议

生效日期：2026 年 11 月 22 日

本隐私协议说明 MeshStream 在您注册、使用控制台、接入 SDK、运行 Web Demo 或使用相关服务时，如何收集、使用、保存、共享和保护信息。我们只处理提供服务、保障安全、计量结算和履行法律义务所需的信息。

MeshStream 是由个人运营者提供的品牌和服务名称，目前不代表已设立的公司、法人或独立法律实体。运营主体、正式服务通知地址、适用法律和争议解决地以本协议当前版本、订单或法律通知中公布的信息为准。对于您通过 SDK 或服务处理的终端用户个人信息，您通常是决定处理目的和方式的责任方，MeshStream 按您的指示提供受托技术处理。您应自行向终端用户提供符合法律要求的隐私告知并取得必要授权；本协议不替代您面向终端用户的隐私政策。

## 一、我们处理的信息

### 1. 账号与联系信息

包括邮箱地址、密码哈希、邮箱验证状态、注册区域、账号状态、登录时间和必要的安全审计记录。我们不会保存您的明文密码。

### 2. 应用与配置数据

包括应用名称、App ID、SDK Key 的标识信息、播放域名、区域策略、Tracker 和回源配置、白名单及控制台操作记录。Key 的秘密部分不应出现在客户端日志、公开代码或媒体 URL 中。

### 3. SDK 与设备运行信息

在您接入 SDK 并播放内容时，可能处理 SDK 版本、平台、操作系统、浏览器或播放器类型、匿名设备标识、应用版本、网络类型、区域、Peer 能力、连接状态和错误原因。此类信息用于调度、兼容性判断、故障诊断和安全防护。

### 4. 播放与用量信息

包括应用、会话、内容标识、媒体协议、分片请求结果、P2P 下载量、CDN 回源量、命中情况、播放鉴权结果、延迟、失败和降级原因。我们通常不需要保存媒体正文；如为处理安全事件、技术问题或法律义务需要保存相关日志，会采取必要的访问控制和期限限制。

### 5. 交易与客户支持信息

包括套餐、额度、订单、账单状态、工单、反馈和您主动提供的排障材料。当前未接入在线支付的环境不会由 MeshStream 保存完整银行卡或支付账户信息。

## 二、我们如何使用信息

我们使用上述信息来：

- 创建和保护账号，发送验证、重置和服务通知；
- 提供 P2P 调度、CDN 回源、会话管理、跨端兼容和播放降级；
- 计算套餐、每日额度、加油包和其他用量；
- 生成控制台统计、诊断报告、告警和验收证据；
- 检测滥用、攻击、盗用 Key、异常流量和违反协议的行为；
- 修复故障、改进 SDK 与服务质量，并履行法律、监管和争议处理义务。
- 识别关联账号、阻止额度滥用、保护 MeshStream、客户及其他用户的安全。

我们不会将您的媒体内容、源站凭证或业务数据出售给第三方，也不会使用客户内容制作与客户无关的广告画像。

## 三、P2P 场景下的隐私边界

P2P 连接需要在参与节点之间交换完成连接和分片传输所必需的网络元数据，例如临时 Peer 标识、连接状态和分片请求信息。SDK 不应将源站鉴权头、源站密码、客户私有 Token 或其他敏感请求头发送给 Peer；源站请求应继续由客户自己的 CDN、源站或受控回源链路处理。

MeshStream 会尽量使用匿名或短期标识，并根据调度、风控和统计需要保留必要的连接记录。您应在自己的隐私政策和产品提示中向终端用户说明 P2P 连接、网络元数据和本地缓存行为，并在需要时取得授权。

## 四、Cookies 与本地存储

控制台可能使用浏览器本地存储、会话 Cookie 或类似技术保存登录状态、语言、主题和安全令牌。SDK 可能使用本地缓存保存临时分片、会话状态和性能信息。您可以通过浏览器或系统设置清理这些数据，但可能导致退出登录、缓存失效或播放体验下降。

如果官网启用 Google Analytics，Google 标签会在默认拒绝分析存储的 Consent Mode 下加载；在您通过 Cookie 偏好弹窗明确允许分析前，不会设置或读取分析 Cookie，仅可能向 Google 发送不含分析 Cookie 的测量信号。获得您的许可后，我们才会启用基于 Cookie 的分析，用于了解页面使用情况和改进文档与产品导航。您可以在首次访问时拒绝，也可以通过页脚“法律与合规”中的“Cookie 偏好”入口撤回同意。Google 可能按照其自身的服务条款和隐私政策处理相关测量数据。

## 五、共享、委托与跨区域处理

为提供服务，我们可能向受约束的基础设施、邮件、日志、监控、云存储和客户支持服务商提供必要的信息。服务商只能按照我们的指示处理信息，并应承担保密和安全义务。

这些服务商属于基础设施、邮件发送、日志监控、客服和安全风控等类别。我们会通过合同、权限控制、最小化、加密或其他合理措施约束其处理行为；服务商发生变化时，我们会在适用法律要求的范围内更新相关说明。

您选择的服务区域可能涉及跨区域调度、日志处理或灾备。跨境处理时，我们会根据适用法律采取合同、访问控制、加密、最小化和其他必要措施。除法律要求、保护用户和平台安全或经您授权外，我们不会向无关第三方披露您的信息。

如监管、司法或其他有权机关依法要求提供信息，我们会在法律允许的范围内通知您并仅披露必要范围；如通知会妨碍调查、危及安全或法律禁止通知，我们可以不予通知。

## 六、保存期限

我们按实现业务目的所需的最短期限保存信息：账号信息在账号存续期间保存；安全、审计、用量和结算记录可能在账号终止后继续保存一段合理期限；法律、争议、安全事件或备份要求可能延长保存期限。超过期限后，我们会删除、匿名化或安全隔离相关信息。

发生安全事件、争议、欠费、投诉或法律调查时，相关日志和证据可能在必要期限内继续保存。账号终止后的数据导出、删除及备份处理以《用户服务协议》约定为准。

## 七、您的权利

在适用法律允许的范围内，您可以请求访问、更正、删除账号信息，撤回特定授权，限制或反对部分处理，并获取与您有关的可携带数据。删除账号可能影响未结算订单、审计记录、争议处理和法律留存义务。

您可以通过 `support@meshstream.net` 联系我们。为保护账号安全，我们可能要求您完成身份验证后再处理请求，并在法律规定的期限内回复。

## 八、安全措施

我们采用密码哈希、传输加密、凭证隔离、权限控制、访问审计、速率限制、备份和安全监控等措施保护信息。没有任何互联网传输或存储方式能够保证绝对安全，您也应负责保护密码、SDK Key、源站凭证和控制台访问设备。

如发生可能影响您信息安全的事件，我们会按照适用法律采取补救措施，并在法律要求或合理必要的范围内通过控制台、注册邮箱或其他方式通知您。

## 九、未成年人

服务主要面向开发者和企业用户。未成年人使用服务应获得其监护人或所在组织的合法授权。若您发现未成年人在未获适当授权的情况下向我们提供个人信息，请通过 `support@meshstream.net` 联系我们。

## 十、协议更新与联系我们

我们会根据服务、法律或安全要求更新本协议，并在官网公布新的生效日期。重大变化会通过控制台、注册邮箱或其他合理方式通知。

隐私请求、数据主体权利、安全事件和其他隐私问题：`support@meshstream.net`

## 十一、区域处理与个人信息保护

如控制台或订单标示已启用特定服务区域，选择该区域的账号、租户、应用配置、订单、额度、用量和安全审计数据可能优先由对应区域的控制面处理；为提供全球接入、故障恢复、邮件发送、支付、监控或客户支持，必要信息仍可能由其他地区的受约束服务商处理。服务区域不代表 MeshStream 的运营主体或适用法律所在地，也不保证所有数据仅在该区域处理或保存。未标示启用的区域不构成数据存储位置或可用性承诺。

对于因客户、终端用户、运营主体或处理地点而适用的个人信息保护法律，我们会按照适用法律履行收集、使用、披露、保护、保存和删除义务，并采取访问控制、加密、最小化、审计和供应商管理等措施。跨境传输仅限于提供服务、履行法律义务或保护安全所必需的范围，并采取适用法律要求的保护措施。

如您代表客户使用 MeshStream 处理终端用户信息，您通常负责确定处理目的和合法依据、向终端用户提供告知、取得必要同意并响应其请求；MeshStream 按您的书面指示提供受托处理。发生可能影响个人信息安全的事件时，我们会在合理可行范围内及时通知受影响客户并配合调查、补救和法定通报。

区域数据保存位置、服务商清单、保存期限和隐私联系人可能随服务架构变化而更新；最新信息以本协议、控制台、订单和相关法律通知为准。
