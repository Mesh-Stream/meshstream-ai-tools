# Key、应用与内容标识

- **应用**：控制台中的业务归属单元。应用下可以创建多个 SDK Key，并统一查看用量和播放数据。
- **SDK Key**：应用的客户端接入标识，可按平台创建多个。它不是管理员密码，也不应被当作服务端密钥使用。
- **内容标识**：用于判断不同播放请求是否属于同一内容。SDK 会根据播放地址自动识别；地址带动态签名时，可以传入稳定的 `contentId`。

SDK Key 可以出现在客户端代码中，但不能替代管理后台的管理员凭证。Key 是否启用、是否允许 P2P 和是否允许移动网络加速由平台配置控制。

## 常用术语

| 术语 | 统一含义 |
| --- | --- |
| Peer | 参与同一内容播放的其他设备；本设备可以从 Peer 下载，也可以向 Peer 上传已获取的媒体分片 |
| P2P 下载流量 | 本设备通过其他设备获取的媒体流量，也是 MeshStream 的计费流量 |
| P2P 上传贡献 | 本设备向其他设备分享的媒体流量，不计 MeshStream 额度 |
| CDN 回源 | P2P 不可用、未命中或超时时，从客户 CDN 获取媒体分片 |
| 播放地址 | 客户提供给 SDK 的原始媒体地址，通常是 HLS 的 `.m3u8` 或 DASH 的 `.mpd` |
| SDK 播放地址 | SDK 返回给播放器使用的播放地址；业务代码应使用它播放，不要重新拼接原始地址 |
