# 用量与计费

MeshStream 只按实际产生的 **P2P 下载流量**计入额度。

## 计量方式

- 计费对象：`p2pDownloaded`，也就是播放器实际从其他设备接收的 P2P 媒体字节。
- 不计费对象：CDN 回源流量、P2P 上传贡献，以及平台服务产生的控制和统计流量。
- CDN 回源费用仍按客户自己的 CDN 服务商规则结算。
- 计量维度：应用、Key、平台。
- 会话未结束或未调用 `dispose` 的播放不生成完整计量记录。

## 配额与套餐

- 每个应用在控制台有当前套餐的 P2P 下载用量配额。
- 每日赠送额度、签到奖励、套餐额度和加油包都只抵扣 P2P 下载流量。
- 当 P2P 未命中时，SDK 自动回到客户 CDN，播放继续但不会产生 MeshStream 额度扣减。
- 接近配额时，控制台会展示用量进度；超出后播放将自动回落至客户 CDN。

## 账单与支付

- 控制台提供账单、订阅和用量明细。
- 如需调整套餐或有大额流量计划，请在控制台联系平台方。

## 控制台字段口径

| 字段 | 作用 | 是否扣额度 |
| --- | --- | --- |
| P2P 下载流量 | 观察 P2P 实际分发效果 | 是 |
| CDN 回源流量 | 观察降级和命中率 | 否 |
| P2P 上传贡献 | 观察设备分享能力 | 否 |

命中率仍按 `P2P 下载流量 / (P2P 下载流量 + CDN 回源流量)` 计算，因此后台看到的 CDN 流量不会消失，只是不再混入额度扣减。
